# Third-party components

## Runtime and build dependencies shipped in this repository

None. The engine, the CLI tool and the test suite use only the C++20 standard library.
There is no vendored code in `include/` or `src/`, no bundled library under
`third_party/`, and no dependency is downloaded during a normal build.

## Optional dependency

| Component | Version | Source | Licence | Used for | Obligations |
| --- | --- | --- | --- | --- | --- |
| GLFW | 3.4 | https://github.com/glfw/glfw | zlib/libpng | Windowing and OpenGL context for `FE3D_ENABLE_OPENGL_RENDERER=ON` / `FE3D_BUILD_DESKTOP_APP=ON` only | Keep the copyright and licence notice in binary distributions; it is not required to publish modifications. Off by default, never fetched unless `FE3D_FETCH_GLFW=ON`. |

`cmake/Fe3DDependencies.cmake` looks for a system GLFW first. When
`FE3D_FETCH_GLFW=ON` and GLFW is missing, it downloads the pinned 3.4 release and its
licence text, and builds it as a static subproject. The pinned version is recorded in
that file, and the fetched copy keeps its own `LICENSE.md`.

## Build tools and compilers

CMake, Ninja, GCC, Clang, MSVC, Xcode and Zig are build-time tools, not distributed
parts of the engine, and are used under their own licences. The Linux verification
recorded in `docs/BUILDING.md` used Zig 0.17.0's bundled Clang and libc++ because the
authoring machine had no system C++ compiler installed; nothing in the repository
depends on Zig, and any C++20 toolchain builds the same sources.

## Generated content

Built-in primitive meshes (cube, plane, sphere) and the demo scene are generated by
first-party code in `src/rendering/MeshLibrary.cpp` and `src/engine/DemoScene.cpp`.
No third-party model, texture, font or other asset is included.

## Licence of this project

Final Effect 3D itself is GPL-3.0-only (`LICENSE`). Distributing a binary - including
one that links the optional GLFW dependency - means shipping the corresponding source
under the GPL and keeping third-party notices intact.
